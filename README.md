The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

# RecruitPro – Recruitment Management System

## About the Project
RecruitPro is a web-based Recruitment Management System developed using React.js. It simplifies the recruitment process by providing separate features for Candidates and Recruiters.

## Features

### Candidate
- Browse and explore job opportunities.
- View job details.
- Apply for jobs.
- Save favorite jobs.
- Track submitted applications.
- Access a personalized candidate dashboard.

### Recruiter
- Add new job postings.
- View available jobs.
- Edit existing job details.
- Delete job postings.
- Access the recruiter dashboard.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Redux Toolkit
- Axios
- JSON Server

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd YOUR_PROJECT_FOLDER
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the JSON Server using the configured database file and port.

5. Start the React development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in the terminal.

## Project Purpose
The main objective of RecruitPro is to provide a simple and user-friendly platform for managing job postings and candidate applications.

## Future Enhancements
- Resume upload and management.
- Advanced job search and filtering.
- Email notifications.
- Improved application status tracking.
- Production-ready backend and database integration.
